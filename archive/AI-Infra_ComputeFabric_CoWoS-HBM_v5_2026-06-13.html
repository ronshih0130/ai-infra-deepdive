EXPLAIN IT SIMPLY · 白話版

A modern AI chip isn't one chip — it's a GPU die plus a stack of memory chips (HBM) glued onto a silicon "tray" called an interposer. That gluing step — done by TSMC's CoWoS packaging — is the real traffic jam: you can make the chips faster than you can assemble them together. So the shortage everyone calls "a memory shortage" is really an assembly (packaging) shortage. The question for an investor: do you buy the foundry that owns the assembly (TSMC), the memory makers (Micron/SK Hynix), or the machine makers that build the gluing tools (BESI)? And which of those still has upside left after the run they've already had?

THE STACK · 分層 (read first)
Die a bare chip (GPU or memory) · Interposer the silicon "tray" dies sit on · CoWoS TSMC's process bonding dies + memory onto the interposer · Accelerator the finished GPU module · System the rack of accelerators.
6-TERM GLOSSARY · 名詞

03

The chokepoint & severity

卡點與嚴重度

CoWoS advanced packaging (with HBM co-binding)

You can fabricate GPU and memory dies faster than you can assemble them together. TSMC's CoWoS is ramping 35k→130k wafers/mo yet stays sold out; HBM is fully allocated for 2026. Both must be available simultaneously to ship one accelerator, so the effective ceiling is the tighter of the two at any moment. Unlike the optics EML, capacity here is being added aggressively — which caps how long the rent lasts.

VARIANT PERCEPTION vs CONSENSUS · 變異認知

Consensus: "AI is short of memory — buy HBM." The disaggregation: the binding gate is packaging assembly, not memory cells; and the purest, least-diluted way to own the packaging bottleneck is the hybrid-bonding tool maker (BESI/ASMPT), not the $T foundry whose CoWoS rent is <5% of revenue, nor the cyclical memory makers. The catch that keeps it contrarian: HBM4 reportedly stays on microbumps, postponing the hybrid-bonding HBM catalyst to HBM4E / logic-3D (2027+) — so the tooling thesis is a 2027 story the price has partly run ahead of. If we're wrong, it's because CoWoS capacity catches up faster than demand (the build-out is real) and the rent compresses by 2027.

Who captures the rent?

The decisive test is margins. TSMC raises CoWoS pricing but the rent is <5% of group revenue — diluted. HBM makers keep rent only while sold out; the buyers (Nvidia) pre-pay and lock allocation, capping it. Tool makers (BESI) sell into every packaging line regardless of who wins — the cleanest rent capture, but smallest TAM and a delayed HBM catalyst. Conclusion: no single name is both the gate and a pure-play — the structural compromise of this layer.
